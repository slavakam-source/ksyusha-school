# Ксюшина школа — голосовой ИИ

Первая версия сайта: `index.html` — самостоятельный тренажёр по заданиям № 6 и № 7. Страница `voice.html` — голосовой режим с ИИ, который требует отдельного сервера и пока не активирован.

## Запуск голосового сервера без домашнего ПК

1. Создайте Node.js Web Service на HTTPS-хостинге, например Render или Railway, из этого репозитория.
2. Используйте Node.js 22.6+ и команду `npm start`.
3. В защищённых переменных окружения хостинга (не в GitHub!) задайте:
   - `OPENAI_API_KEY` — секретный ключ проекта OpenAI.
   - `LESSON_ACCESS_CODE` — длинный случайный код, известный родителю.
   - `ALLOWED_ORIGIN=https://slavakam-source.github.io`
4. Проверка: `https://YOUR-SERVER/health` возвращает JSON со статусом ok.
5. Откройте `https://slavakam-source.github.io/ksyusha-school/voice.html?server=https%3A%2F%2FYOUR-SERVER`, заменив YOUR-SERVER на реальный HTTPS-адрес.
6. Родитель вводит код доступа и запускает урок.

Основной API-ключ хранится только на сервере. **Нельзя** добавлять его в GitHub, HTML-файлы или адресную строку.

Модель получает ограничение: только математика, только задания № 6 и № 7, наводящие вопросы вместо готовых ответов. Абсолютно гарантировать соблюдение темы одним промптом нельзя.

Это прототип для совместных занятий со взрослым. Перед самостоятельным или широким использованием нужны более строгая авторизация, постоянное хранилище лимитов, серверное ограничение длительности и контроль затрат. Для ребёнка 9 лет использование предполагает непосредственное участие взрослого.

Подробности интеграции WebRTC: https://developers.openai.com/api/docs/guides/voice-webrtc?voice-api=live
